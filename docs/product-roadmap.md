# Product Roadmap

## Practitioner-to-Practitioner Medical Negligence LMS

This roadmap describes the planned development of the LMS from the initial foundation through to an interactive practitioner training platform.

---

# Phase 1 — Project Foundation

The first phase establishes the basic technical and organisational structure.

### Goals

- Create the GitHub repository
- Establish project documentation
- Define the learning model
- Define user roles
- Establish the initial database design
- Establish security and content governance principles

### Status

**In progress**

---

# Phase 2 — LMS Foundation

The platform will provide the basic functionality required for practitioners to access learning material.

### Features

- User registration
- Secure login
- Practitioner profiles
- Practitioner roles
- Course catalogue
- Course modules
- Individual lessons
- Learning objectives
- Learner progress tracking
- Basic dashboard

### Intended user roles

- Attorney
- Advocate
- Medical Expert
- Facilitator
- Administrator

---

# Phase 3 — Learning Content

The LMS will begin supporting different forms of educational material.

### Content types

- Legal literature
- Medical literature
- Legislation
- Case law
- Practice notes
- Videos
- Case studies
- Diagrams
- Practical exercises
- Quizzes

Each item should contain appropriate source, jurisdiction and review information.

---

# Phase 4 — Case-Based Learning

The platform will introduce realistic medical negligence litigation scenarios.

A typical case simulation may include:

```text
Case Background
       ↓
Medical Records
       ↓
Chronology
       ↓
Legal Issues
       ↓
Expert Evidence
       ↓
Causation
       ↓
Litigation Strategy
       ↓
Advocacy
       ↓
Assessment
```

Learners should be required to analyse information and make professional decisions rather than simply recall information.

---

# Phase 5 — Interactive Training Games

The LMS will introduce games designed around practical professional skills.

### Initial game concepts

#### Expert Challenge

The learner selects appropriate experts for a fictional case while working within defined constraints.

#### Chronology Detective

The learner analyses medical records and identifies important events, gaps and inconsistencies.

#### Report Room

The learner compares fictional expert reports and identifies methodological or evidentiary issues.

#### Cross-Examination Lab

The learner prepares questions for a simulated expert witness.

#### Strategy Table

Practitioners make decisions about a fictional litigation strategy and receive feedback based on the consequences of those decisions.

---

# Phase 6 — Practitioner Collaboration

This phase introduces collaborative learning.

Practitioners will be able to participate in structured sessions involving different professional perspectives.

For example:

```text
              SIMULATED CASE
                    │
       ┌────────────┼────────────┐
       │            │            │
    ATTORNEY      ADVOCATE    MEDICAL EXPERT
       │            │            │
       └────────────┼────────────┘
                    │
              TEAM DECISION
                    │
                 FEEDBACK
```

The purpose is to allow practitioners to understand how different professionals approach the same medical negligence problem.

# Phase 7 — Facilitator Platform

Facilitators will eventually be able to create and manage their own practitioner training sessions.

### Facilitator features

- Create courses
- Create modules
- Create lessons
- Add literature
- Add videos
- Create case studies
- Create games
- Create assessments
- Create cohorts
- Assign learning activities
- Monitor learner progress
- Provide feedback

---

# Phase 8 — Assessment and Certification

The platform may eventually support:

- Knowledge assessments
- Practical assessments
- Case-analysis exercises
- Peer assessment
- Facilitator assessment
- Completion certificates
- Training records

Certification requirements should be defined separately and should not be implied simply by completing online content.

---

# Phase 9 — Analytics

The platform may eventually provide learning analytics such as:

- Module completion
- Assessment performance
- Participation
- Areas of difficulty
- Cohort activity
- Facilitator reports

Analytics should be designed to support learning and should respect appropriate privacy and professional requirements.

---

# Phase 10 — Advanced Platform

Future development may include:

- Content versioning
- Multiple jurisdictions
- Accessibility improvements
- Mobile optimisation
- Advanced facilitator analytics

---

# Development Principle

The platform should not attempt to build everything at once.

The first usable learning loop should be:

```text
LOGIN
  ↓
COURSE
  ↓
MODULE
  ↓
LESSON
  ↓
ACTIVITY
  ↓
ASSESSMENT
  ↓
FEEDBACK
  ↓
PROGRESS
```

Once this loop works reliably, additional features can be added around it.

---

# Long-Term Vision

The long-term goal is to create a professional learning environment in which medical negligence practitioners can learn **with and from one another**.

The platform should combine:

**Knowledge + Experience + Case Analysis + Collaboration + Practice + Feedback**

rather than functioning only as a digital library.
